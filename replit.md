# Fahari Gardens

## Run on Replit

The project uses a Vite development server. The Replit workflow runs:

```bash
npm run dev
```

The server is configured for Replit's preview on port `5000`.

## Run in VS Code

1. Open the project folder in VS Code.
2. Make sure Node.js is installed.
3. Open the integrated terminal and install dependencies:

   ```bash
   npm install
   ```

4. Start the development server:

   ```bash
   npm run dev
   ```

5. Open the local URL printed by Vite, usually `http://localhost:5000`.

For a production build, run:

```bash
npm run build
npm run preview
```

## Remaining integrations

This is currently a frontend-only site. Booking availability, payments, contact/newsletter delivery, branded maps, and production photography still need to be connected before launch. See `README.md` for the original integration notes.
